# Ошибки распознавания речи

Типичные ошибки Whisper в курсах по ИБ. Ассистент добавляет строку, когда находит новый случай.

`python -I scripts/transcript_fix.py scan <транскрипт>` ищет варианты из первой колонки (без учёта регистра, целыми словами) и только показывает строки. Заменять или нет, решает ассистент по смыслу: например, «АД» может быть и Active Directory, и обычным словом.

Первая колонка: варианты через запятую. Вторая: как правильно. Третья: когда это ошибка.

|---|---|---|
| Patenat, Patanat, Патенат | PT NAD | |
| ЕДС, ИДС | IDS | |
| CM, Сием | SIEM | |
| сурикаты | Suricata | |
| ЗИГ | Zeek | |
| СЭНС | SANS | |
| лангрид | лонгрид | |
| ИП | ИБ | когда речь об отрасли |
| ростов СЗИ | хостовых СЗИ | |
| АД | AD | когда речь об Active Directory |
| Postive Technologies | Positive Technologies | |
