## Как пользоваться

- Новый материал → файл `notes/<неделя>/m<id>-<slug>.md` по шаблону `templates/note.md`, строка в `sources/manifest.csv`, строка в таблице выше.
- Видео → `media/` (не коммитится), транскрипт → `transcripts/`.
- Файлы материалов (PCAP, архивы и т. п.) → `attachments/<неделя>/` (не коммитятся), строка в `sources/attachments.csv`. Исходное имя файла хранится в реестре.
- Свои захваты и отчёты из лабораторных → `labs/<неделя>/`.
- Незнакомые термины и аббревиатуры: [[glossary]]. В заметках первое упоминание термина ссылается на глоссарий, при наведении в Obsidian всплывает статья.
- Ассистент работает по правилам из [[AGENTS]]: сам в LMS ничего не открывает без просьбы, тесты не проходит, ответы в тренажёр не отправляет.
