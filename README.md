# Шаблон для конспектов курса Positive Education

Шаблон помогает учить курс вместе с Claude Code (десктопное приложение): конспекты, транскрипты видео, файлы материалов (PCAP, архивы, бинарные файлы и т. п.), вопросы для повторения и учёт прогресса.
Работает на macOS и Windows. Содержимого курса в шаблоне нет, только метод и скрипты.

## Как начать

**Вручную (Claude этого сделать не может):**

1. Установите приложение Claude, войдите в аккаунт.
2. Установите сертификаты Минцифры: https://www.gosuslugi.ru/landing/crt (подробнее в [[SETUP]], шаг 0). Без них сайт LMS не откроется. Перезапустите браузер и Claude.
3. Нажмите **Use this template** на GitHub и создайте свой **приватный** репозиторий. Клонируйте его (`git clone`, нужен Git) или скачайте папкой.
4. Откройте папку в приложении Claude, вкладка Code.
5. Откройте LMS во встроенном браузере приложения и войдите в аккаунт. Страница должна открыться без предупреждения о сертификате.

**Через Claude (скопируйте сообщение в чат; он спросит разрешение перед каждой установкой):**

6. Подготовка окружения:

   ```
   Прочитай SETUP.md и подготовь окружение: установи недостающее ПО и Python-пакеты, потом запусти scripts/doctor.py и покажи результат.
   ```

7. Настройка под ваш курс:

   ```
   /init-course
   ```

Дальше работайте обычными просьбами, например: «Сделай конспект материала 1-08».

## Что внутри

- [[AGENTS]]: правила работы ассистента.
- `scripts/`: `doctor.py` (проверка окружения), `transcribe.py` (видео в текст, сам выбирает движок и модель), `attachment_register.py` (учёт скачанных файлов материалов: PCAP, архивы, бинарные файлы).
- `templates/note.md`: шаблон конспекта.
- Профили курса (`network`, `general`, `attachments`): задаются в `course.md` через `/init-course` и включают нужные части. Подробнее в [[AGENTS]], раздел Course profile.
- `.claude/skills/init-course/`: настройка под ваш курс.

## Важно

Этот шаблон публичный: в нём нет содержимого курса. Ваша копия должна быть **приватной**: в ней будут `notes/`, `transcripts/`, `media/`, `attachments/`, то есть материалы курса. Не публикуйте их.
